# استوديو عروض الباوربوينت السينمائية | مستر محمد ناصر بدوي
### Mr. Mohamed Nasser Badawy - Cinema Presentation Studio & AI Cartoon Engine

تطبيق ومهارة ذكاء اصطناعي احترافية مخصصة لتوليد عروض باوربوينت سينمائية (**16:9 Widescreen**) لمستر **محمد ناصر بدوي**، بنظام ألوان **Dark Modern Cinema** فائق التناسق، مع **رسوم كارتونية توضيحية للأطفال والطلاب** و**حركات باوربوينت تتابعية ناعمة (PowerPoint Click Animations)**.

---

## 🌟 أبرز التحديثات والمميزات الجديدة

1. **تناسق ألوان سينمائي متقدم (Dark Modern Cinema Palette):**
   - خلفية كحلي ليلي عميق (`#0A1128`) مع إضاءات سينمائية ناعمة بدون دوائر مشوشة.
   - بطاقات سلايت زجاجية فخمة (`#162032`) مع حواف أنيقة (`#2A3F5F`).
   - لمسات كهرمانية وذهبية راقية (`#E5A93C`) للتركيز والشارات.
   - أزرق كهربائي هادئ (`#4CC9F0`) للنطق والتشكيل، وأخضر زمردي (`#2EC4B6`) للأمثلة الإيجابية.

2. **رسوم كارتونية توضيحية تعليمية (AI & 2D Cartoon Explainers):**
   - توليد وإدراج رسوم كارتونية مبهجة وجذابة تشرح كل كلمة، فعل، أو قاعدة تجويد للأطفال والطلاب بصرياً.
   - تخزين مؤقت وذكي للرسومات التوضيحية داخل `assets/illustrations/`.

3. **توزيع الشريحة السينمائي المنقسم (Hero Split Layout):**
   - نصف الشريحة للرسم الكارتوني التوضيحي داخل إطار سينمائي متوهج يحمل شارة `🎨 Cartoon Explainer`.
   - النصف الآخر للمصطلح، النطق الصوتي الفونيتكس، الشرح المركز، نقاط الاستخدام، وصندوق المثال التطبيقي.

4. **حركات باوربوينت تتابعية ناعمة (Native PowerPoint Animations):**
   - ظهور العناصر تدريجياً بنقرات الماوس (Progressive Reveal on Click) لشد انتباه الطالب أثناء الشرح.
   - انتقالات ناعمة وحريرية بين الشرائح (Smooth Fade Transitions).

5. **شريحة افتتاحية وختامية متكاملة:**
   - شريحة غلاف تضم بطاقة مستر محمد ناصر بدوي وشارات المسار المعتمد.
   - شريحة ختامية تضم الحديث الشريف / العبارة التحفيزية، مع بطاقات واتساب وفيسبوك للتواصل الفوري.

## 💻 طريقة التشغيل على ويندوز (Windows)

### بنقرة واحدة:
1. اضغط مرتين على الملف:
   ```cmd
   start_app.bat
   ```
2. ستفتح الواجهة التفاعلية تلقائياً في متصفحك على:
   ```
   http://127.0.0.1:8505
   ```
3. اختر المسار التعليمي، اكتب عنوان الدرس، واختر مصدر المحتوى (ملف أو يوتيوب أو نص)، ثم اضغط **توليد عرض الباوربوينت السينمائي**.

---

## 💻 طريقة التشغيل عبر سطر الأوامر (CLI)

```bash
# توليد عرض إنجليزي للطلاب مع الرسوم الكارتونية والحركات
python3 cli.py --title "Irregular Verbs for Kids" --track students --text "Lesson about action verbs: Run, Eat, Swim and Sleep with cartoon illustrations."

# توليد عرض تجويد للأعاجم
python3 cli.py --title "Rules of Noon Sakinah" --track foreigners --text "Explanation of Izhar and Idgham with clear articulation rules."
```
